# Анализ банковских операций

Приложение для обработки выгрузки операций Т-Банка (Excel). Реализованы:
- Генерация JSON для главной страницы (приветствие, расходы по картам, топ-5 транзакций, курсы валют, цены акций S&P500).
- Сервис "Инвесткопилка" – расчёт накоплений за счёт округления трат.
- Отчёт "Траты по категории" за последние 3 месяца с сохранением в файл.

## Установка и запуск

1. Клонировать репозиторий.
2. Установить зависимости: `poetry install`
3. Создать файл `.env` по образцу `.env_template` и добавить API-ключ Alpha Vantage.
4. Поместить файл с транзакциями `operations.xlsx` в папку `data/` (или указать путь в коде).
5. Запустить демонстрационный модуль: `python src/main.py`

## Тестирование

Запустить тесты: `pytest tests/` с проверкой покрытия: `pytest --cov=src tests/`
